# Stay Offline 🎮

A captivating adventure game about a boy searching for his long-lost brother through trials, obstacles, and riddles. Discover an unexpected twist ending that will leave you questioning everything!

## 📖 Story

You play as a determined boy venturing into a mysterious world filled with challenges. Your mission: find your long-lost brother. Along the way, you'll encounter:
- **Riddles** that test your wit and intelligence
- **Obstacles** that require skill and precision to overcome
- **Trials** that push you to your limits

But beware... as you progress through stages and uncover the truth, you'll discover that your brother has been orchestrating your suffering all along. The twist ending will shock you!

## 🎯 Key Features

- **Multiple Stages**: Progress through increasingly difficult levels
- **Diverse Challenges**: Solve riddles, navigate obstacles, and complete trials
- **Engaging Narrative**: Follow an intriguing story with a shocking plot twist
- **Immersive Gameplay**: Experience a world designed to test both mind and skill
- **Replayability**: Discover new secrets on subsequent playthroughs

## 🚀 Getting Started

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Kangwa501/Stay-offline.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Stay-offline
   ```

3. Run the game:
   ```bash
   ./start-game
   ```

### System Requirements

- OS: Windows, macOS, or Linux
- Processor: Dual-core 2.0 GHz or higher
- RAM: 2GB minimum
- Storage: 500MB free space
- Display: 1024x768 resolution minimum

## 🎮 Gameplay Overview

### Stages

The game is divided into multiple stages, each with unique environments and challenges:

| Stage | Environment | Difficulty | Key Challenge |
|-------|-------------|-----------|----------------|
| 1 | Forest Entrance | Easy | Introduction & Tutorials |
| 2 | Mountain Pass | Medium | Complex Riddles |
| 3 | Ancient Temple | Hard | Combined Trials |
| 4 | Final Confrontation | Expert | The Truth Revealed |

### Challenge Types

**Riddles**: Test your logic and creativity
- Example: "I speak without a mouth and hear without ears. What am I?" (Answer: Echo)

**Obstacles**: Require timing and precision
- Trapdoors, moving platforms, environmental hazards

**Trials**: Comprehensive challenges combining multiple elements
- Combat trials, endurance tests, wisdom challenges

## ❓ FAQ

**Q: How long is the game?**  
A: The game takes approximately 2-4 hours to complete depending on difficulty and exploration.

**Q: Can I play on different devices?**  
A: Currently available for Windows, macOS, and Linux. Mobile versions coming soon!

**Q: Is there a multiplayer mode?**  
A: The current version is single-player. Multiplayer features are planned for future updates.

**Q: Can I skip the story and jump to stages?**  
A: No, the story must be experienced in order for the plot twist to have maximum impact.
